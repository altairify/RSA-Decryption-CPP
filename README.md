# RSA-Decryption-CPP

A C++ application that decrypts RSA-encrypted messages by implementing the mathematical principles behind RSA cryptography, including prime factorization, modular arithmetic, and modular exponentiation.

---

## 📖 Overview

This project was completed as part of my Computer Science coursework at the University of California, Riverside.

The goal of this project was to build an application capable of decrypting RSA-encrypted messages without relying on external cryptography libraries. Instead, I implemented the core algorithms myself to better understand how RSA encryption and decryption work behind the scenes.

---

## 🎯 Objectives

- Implement the RSA decryption algorithm in C++
- Apply modular arithmetic and number theory concepts
- Practice object-oriented programming and algorithm design
- Strengthen problem-solving and debugging skills

---

## ⚙️ Features

- Prime number verification
- Greatest Common Divisor (GCD) calculation
- RSA private key generation
- Modular exponentiation
- Decryption of RSA-encrypted ciphertext into readable plaintext
